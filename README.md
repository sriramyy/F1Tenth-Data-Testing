# F1Tenth Frenet Post-Processing

Find saved cleaned results in `data/saved_results/`.

### Using
Get requirements from `requirements.txt` to create a venv.

Place the input data csv in the `data/input` folder.  

Run the `process_data.py` file. This will go through each of the input files and output their corrected version in the `data/output` folder with `_fixed` appended on the end of the file.
